# CrossExam 质询室

> **把你准备好的简历交给一整间面试官，先替你审一遍。**
> 多 Agent 对抗式面试沙盘 —— 不是让 AI 帮你写简历，是让一群 AI 面试官告诉你简历里哪句话站不住。

参加：**全国高校 Vibe Coding 开发挑战赛 · AI创新应用挑战赛**（赛道 id 10039）。

## 这是什么

你投出去的每一份简历，面试官都会挑着问。真正让人翻车的不是排版，是
**简历里写了但你其实答不上来的那句话**。

CrossExam 把这件事提前：喂入简历 + 目标岗位 JD，系统抽出简历里一条条**可被追问的主张**，
按主张类型组成一间面试官（技术 / HR / 业务主管 / 压力面试官），并发向你追问。
你答完，它给每条主张一个结论，并**反推回简历**告诉你该改哪一句、怎么改。

| 阶段 | 做什么 |
| --- | --- |
| 投料 | 简历 + 目标岗位 JD |
| 拆解 | 抽出「可被追问的主张」，每条锚定简历原文 |
| 组庭 | 依据主张与 JD 生成面试官阵容 |
| 对抗 | 多面试官并发追问，你回答，它继续追问 |
| 判定 | 每条主张：站得住 / 表述过度 / 证据缺失 / 与原文矛盾 / 无法回答 |
| 反推 | 定位到原文片段的简历修改建议 |

## 快速开始

> ⏳ 施工中。10 分钟极速复现指南将在 P5 阶段完整补齐。

```bash
git clone <repo-url>
cd crossexam
npm install
cp .env.example .env     # 按需填写模型 Key
npm run dev
```

**没有 API Key 也能跑**：`CROSSEXAM_MODE=replay` 会离线回放已录制的模型响应，
完整跑通全流程。这是为「任何评委都能一键复现」设计的。
