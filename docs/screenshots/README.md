# docs/screenshots —— 界面截图（由命令生成，不是手点的）

    npm run build && npm run shots

生成器是 [tools/ui-shots](../../tools/ui-shots/README.md)：真起服务、真起浏览器（系统 Edge/Chrome，走 CDP）、
按 `data-shot` 锚点走完一遍操作，顺便把控制台报错当失败。也就是说这批图随时可以重新生成，
而不是「上次截的图」——README、技术文档、演示视频封面都用它们。
