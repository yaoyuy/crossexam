# 录制前检查（演示视频 · 一次录成）

> 配套两份：`docs/video/script.md`（分镜与旁白全文）、`docs/video/teleprompter.md`（照念提词卡，一屏一句）。
> 用法：从第一节往下走，每条都在半分钟内能确认；全部勾掉再按录制键。

## 一、这台机器（录之前 5 分钟）

| # | 检查 | 怎么做 | 期望 |
| --- | --- | --- | --- |
| 1 | 系统静音已开 | 任务栏音量图标：喇叭带斜杠 | 视频里不会混进系统提示音 |
| 2 | **麦克风没有被静音** | 声音设置里看「阵列麦克风 (AMD Audio Device)」 | 旁白能录进去；不要顺手把输入也静音了 |
| 3 | 勿扰模式 + 关通知 | 系统勿扰；退出微信 / QQ / 邮件客户端 | 没有弹窗打断 |
| 4 | 关掉私人窗口 | 全屏录制会拍下整个桌面 | 屏幕上只有终端 + 浏览器 + 录制软件 |
| 5 | 插电 + 关睡眠 | 电源接通；电源计划禁止自动睡眠 | 录到一半不会黑屏 |
| 6 | 分辨率与缩放 | 1920×1080、缩放 100% | 1080p 是赛题硬要求 |
| 7 | 清空剪贴板 | 复制一句无关的话覆盖掉 | 剪贴板里可能躺着密钥 |

## 六、万一录砸了

- 只错在旁白：不用重录全片，从该节开头重录一段，剪辑拼接即可（每节都是独立场景）。
- 错在数字：先跑 `npm run verify` / `npm run repro` 取真实值，改脚本与提词卡，再重录那一节。
- 错在画面里露了隐私：立刻删掉这一段素材，别只删成片。
