# Prompt 链快照索引

本目录下的每一份 Markdown 都由 `npm run export:prompt` 从 DSH 会话日志自动导出，
**不是事后补写的**——包含完整的用户提问原文、AI 回复、思考过程与工具调用。

单个会话过长时会按体积分页，文件名带 `-2` / `-3` 这样的序号；
**内容一个字都没有删**，只是为了每个文件都能在网页上直接打开（超过 1 MB 的 Markdown 网页只给下载）。

生成命令：

```bash
npm run export:prompt
```
