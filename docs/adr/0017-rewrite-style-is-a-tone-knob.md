# ADR-0017：改写风格只是措辞旋钮，不进契约指纹

- 状态：已采纳（2026-10-27，P11 的 B1）
- 相关：决策 D53、发现 F65 / F66、`packages/shared/src/style.ts`、`packages/server/src/orchestrator/suggest.ts`、`packages/web/src/components/IntakePanel.tsx`

## 背景

同一处「表述过度」，有人希望只删几个形容词，有人希望整句重写。已经有两个可拨的旋钮（追问强度、播放节奏），
改写风格是第三个，问题是：它该不该影响意图契约的指纹？

## 决策

1. **三档只调措辞收敛程度**：`conservative` / `normal` / `bold`（界面名：保守 / 常规 / 敢改），
   写在 `REWRITE_STYLE_GUIDE` 里进 suggest 阶段的 System Prompt。
2. **三条红线任何档位不变**：不许出现简历原文没有的数字、不许把参与写成主导、`before` 必须锚得回原文。
   实现上没有「放宽」的开关——2.6.2 的四道闸门在 `suggest.ts` 里照样逐条执行。
3. **档位不进契约指纹**。指纹只由 `IntentContract` 决定；风格随 `session.meta.style` 落库，
   为的是重开历史会话与报告抬头能说清「这一场改得多狠」。
4. **档位进提示词**，因此换档＝换指纹＝换卡带：离线演示的 suggest 卡带从 4 盘涨到 12 盘（4 条建议 × 三档）。

## 取舍

- 档位不进指纹，意味着「同一份契约 + 两个风格」在指纹上完全一致。这是有意的：指纹回答的是「谁在问」，
  不是「改得多狠」。追问强度放在指纹里（ADR-0014）也是因为同一个理由——它改的是预算，预算属于契约。
- 代价是离线演示的卡带数量随旋钮数量相乘。三档追问强度 × 三档改写风格 = 9 种组合，全部录一遍 56 盘（现状 2026-10-28：版本对比落成后每组连跑两场，共 **149 盘**）；
  再加一个三档旋钮就会变成上百盘。这条线现在就该画在这里：**旋钮只加在真正影响产出的阶段上**。
- `bold` 档的风险最高（模型最容易把「敢改」读成「随意润色」），所以它的档位说明把「不新增任何事实」写在第一句，
  并且由 `newNumbersIn` 在代码里兜底：模型说没加数字不算数。
