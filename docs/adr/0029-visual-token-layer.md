# ADR-0029：视觉令牌层与手写内联图标集

- 状态：已采纳（2026-10-28）
- 相关：ADR-0010（零安装启动器）、ADR-0027（界面按任务分页）、ADR-0028（桌面端是浏览器应用窗口）

## 背景

用户贴来一批参考截图，要求「按参考图统一视觉语言」。这些图共同的特征是：**同一层次的卡片长一样**——
同样的圆角、同样一根 1px 描边、同样的浮起阴影、同样一组强调色，深浅两套配色下都成立。

当时界面里的事实是：二十来个组件各自写着 `rounded-2xl`、`border-white/10`、`shadow-lg` 这类工具类，
同一个「卡片」在五个文件里有五种写法，改一处颜色要翻五个文件，而且深色下看着对、切到浅色就发灰。
另外左侧栏与页头需要一个图标集，候选做法是装 `lucide-react`。

## 决策

1. **加一层视觉令牌**（`packages/web/src/index.css`，约 500 行），只暴露七个变量：
   `--cx-surface` / `--cx-hair` / `--cx-hair-strong` / `--cx-radius`（14px）/ `--cx-radius-sm`（10px）/
   `--cx-shadow` / `--cx-shadow-lift`。组件的圆角、描边、底色、阴影**只准引用这七个**。
2. **两套配色用同一组令牌，深浅各给一份值**：
   浅色写显式值（`#ffffff` / `#e6e9f0` / `#d5dae6` 与两档 `rgba(16, 24, 40, …)` 阴影）；
   深色不重写一遍显式色，而是从既有色阶推：`--cx-surface: color-mix(in oklab, var(--color-ink-900) 94%, transparent)`，
   描边直接取 `--color-ink-800` / `-700`。**换色阶时深色自动跟着走，不需要第二份色板。**
3. **强调色做成八个可选类**：`.accent-ember` / `.accent-mint` / `.accent-sky` / `.accent-violet` /
   `.accent-teal` / `.accent-amber` / `.accent-rose` / `.accent-slate`，每个类只改一个 `--cx-accent`。
   组件里因此**不出现任何色值分支**（没有 `bg-blue-500 dark:bg-blue-400` 这种），要换色只换类名。
4. **图标自己写**（`packages/web/src/components/Icon.tsx`）：`IconName` 是 43 个名字的联合类型，
   `PATHS: Record<IconName, string[]>` 存 24×24 的描边路径，`<svg stroke="currentColor" strokeWidth={1.7}>`，
   `size` 默认 16、页头用 24。**不引图标库。**
5. **不动 tailwind 配置**：令牌写在 `@layer base` 的 `:root` / `[data-theme="light"]` 里，Tailwind 4 的
   `var()` 任意值直接能用，所以这次没有 `tailwind.config` 的改动，也没有新的构建插件。

## 为什么这么选

- **不装图标库的理由是复现成本，不是省字节**：这一页要能在评委机器上 10 分钟内跑起来（AGENTS.md §6 的「十分钟复现」），
  而界面里的图标一共只有四十来个，手写路径的边际成本低于多一个运行时依赖、多一条 `node_modules` 供应链、
  多一处版本冲突的风险。`Icon.tsx` 头部把这条理由写进了注释。
- **不散布色值的理由是「改一次全改」**：AGENTS.md 里那条「跨文档引用的数字必须一次全改」的教训（F93），
  在样式上同样成立——同一种卡片写五遍，第 6 个组件必然写错一种。
- **深色用 `color-mix` 推而不是写死**：用户上一轮就要求过「深色/浅色两套配色只覆盖 CSS 变量，不在组件里写分支」（D29），
  这条沿用同一原则，只是把「一个变量的两套值」换成了「一条令牌两套来源」。

## 后果

- 好处：改配色只改 `index.css` 一处；新组件直接引用令牌就与既有卡片同族；浅色不再需要人肉对色。
- 代价一：CSS 变大了（30.46 → **47.60 kB**，gzip 9.13 kB），换来的是组件里少了几百处重复的工具类。
- 代价二：新增图标要手写 SVG 路径。判断标准是「一个图标 3 分钟内能不能画对」——画不对就换一个意思相近的既有图标，
  不要为此破例装库。
- 代价三：`color-mix` 要求 Chromium 111+ / Safari 16.2+。演示与点测都在 Edge 上跑，这条写进 `docs/tech/06-limits.md` 的浏览器口径。

## 验证

`npm run verify` 全绿（73 文件 / 765 条断言 + 9 项冒烟 + 56 modules + 14 项性能预算，前端 JS gzip 124.58 kB / 预算 128 kB）·
`npm run e2e:ui` **177/177**，控制台 0 报错——**令牌层换掉的是样式，没换掉任何一个选择器**，这正是这条门禁要看的。
